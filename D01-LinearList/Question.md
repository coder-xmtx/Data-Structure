## Question 3

[2015] 用单链表保存 n 个整数，结点的结构如下，且|data| ≤ n ( n 为正整数)。

| data | link |
|------|------|


现要求设计一个时间复杂度尽可能高效的算法，对于链表中 data 的绝对值相等的节点，仅保留第一次出现的节点而删除其余绝对值相等的结点。

例如，若给定单链表 head 如下: 

![Image-Question3.svg](Image/Image-Question3-1.svg)

则删除节点后的 head 为

![Image-Question3-2.svg](Image/Image-Question3-2.svg)

要求：
1. 给出算法的基本设计思想。
2. 使用 C 或 C++ 语言，给出单链表节点的数据类型定义。
3. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
4. 说明你所设计算法的时间复杂度和空间复杂度。

解：可以额外利用一个数组来确认每个节点是否有重复绝对值数据的状态

| 状态   | 0 | 0 | 0 | 0 | 0 | 0 | ... | 0  | 0  |
|------|---|---|---|---|---|---|-----|----|----|
| 数组下标 | 0 | 1 | 2 | 3 | 4 | 5 | ... | 20 | 21 |

如果某个节点的数据是第一次出现，则找到该数据对应的下标，将状态 0 变为 1

如果在后面发现重复数据，则可删除节点

## Question 6

[2019] 设线性表 $L = (a_1,a_2,a_3,\dots,a_{n-2},a_{n-1},a_n)$ 采用带头节点的单链表保存，
链表中的节点定义如下：

```c++
typedef struct node {
    int data;
    struct node* next;
}NODE;
```

请涉及一个空间复杂度为 $O(1)$ 且时间上尽可能高效的算法，重新排列 $L$ 中的各节点，
得到线性表 $L' = (a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\dots)$。

要求：
1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明你所设计算法的时间复杂度和空间复杂度。

解：先把链表从中间断开，对后面一截链表进行反转，再见缝插针
