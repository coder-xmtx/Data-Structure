# 暴力匹配算法

## 前置知识

字符串的模式匹配(Pattern Matching)是指在一个字符串 T 中查找与给定字符串 S 相等的子串。

给定字符串 S 称为模式串，字符串 T 称为目标串。

如果模式匹配失败，则说明目标串T中不存在模式串S。

如果模式匹配成功，则返回模式串S在T中第一次出现的位置，即起始位置。

例如，模式串 S = `bcde`，T = `ababcde`，

若字符编号从 1 开始，则 S 与 T 模式匹配成功，S 在 T 中的起始位置为 4。
