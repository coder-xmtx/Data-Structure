# 红黑树

前提：二叉搜索树

特性：

1. 根和叶子结点（这里的叶子结点指的是外部结点）都是黑色
2. 不存在连续的两个红色结点
3. 任一结点到叶子结点的所有路径的黑结点数量相同

口诀：

**左根右、根叶黑、不红红、黑路同**


## 性质

1. 最长路径不超过最短路径的两倍
2. 插入结点至多两次旋转操作，删除结点至多三次旋转操作

## 插入（官方方法）

新插入的结点默认为红色

若存在冲突：

- 插入结点是根结点 -> 直接变黑
- 插入结点的叔叔是红色 -> 叔父爷变色，爷爷变插入结点
- 插入结点的叔叔是黑色 -> (LL,RR,LR,RL)旋转，然后变色

## 插入（小道方法）

新插入的结点默认为红色

若存在冲突：

- 插入结点是根结点 -> 直接变黑
- 插入结点的叔叔是红色 -> 叔父爷变色，爷爷变插入结点
- 插入结点的叔叔是黑色 -> 自父爷按照“小中大”排成三角，中变黑，小大变红
