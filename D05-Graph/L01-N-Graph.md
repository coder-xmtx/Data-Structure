# 图

## 一、概念

图由两个集合构成，分别是顶点集合 $V$(Vertex) 和边集合 $E$(Edge)，记为 $G=(V,E)$

注意：图至少要有一个顶点（之前的线性表和树都可以是空的，但是图不行）

## 二、术语

- 完全图：边数最多
  - n 个顶点的有向图最多有 n(n-1) 条边，n 个顶点的无向图最多有 n(n-1)/2 条边
- 权：边上的数值，带权图又称为网
- 度：
  - 所有顶点的度数之和 = 边数 × 2
  - 对于有向图：所有顶点入度和 = 所有顶点出度和 = 边数
- 连通：
  - 无向图：n个点的连通图至少需要n-1条边
  - 有向图：如果两个点都相互有路径，那么该图为强连通图，n个点的强连通图至少需要n条边
