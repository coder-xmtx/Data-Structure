# 计数排序

假设输入数组 `arr[n]`，序列长度为 `n`

1. 扫描待排序的数组，确定最大值`max`和最小值`min`
2. 创建一个计数数组`countArr`，用于记录`arr`中各个元素的出现次数，长度为 max - min + 1，初始化全为 0
3. 遍历数组 `arr`，统计每元素的出现次数，结果存储在计数数组中，`countArr[k]`记录的是`min+k`在`arr`中的出现次数
4. 遍历`countArr`，将各个元素依次写入`arr`数组中

## 效率分析

- 空间复杂度：若辅助数组长度为$k$，则空间复杂度为$O(k)$
- 时间复杂度：$O(n+k)$
