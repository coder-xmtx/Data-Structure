# 线索二叉树

利用二叉链表的空指针指向结点的前驱、后继

按照某种遍历顺序构建线索二叉树的过程叫做二叉树的线索化

## 中序线索树找中序前驱/后继

找中序前驱：
- `ltag=1` 左指针指向的就是前驱
- `ltag=0` 前驱为左子树最右下结点

找中序后继：
- `rtag=1` 右指针指向的就是后继
- `rtag=0` 后继为右子树最左下结点（沿着左孩子不断向下直到没有左孩子）

遍历：

中序是左根右，要先确定头是谁，可以从根结点开始不断找左孩子，最左的就是头，
接着按照上面找中序后继的方法来找后继

## 先序线索树找先序前驱/后继

找先序前驱：
- `ltag=1` 左指针指向的就是前驱
- `ltag=0`
  - 如果是整棵树的根，则无前驱
  - 如果是其父的左孩子，则前驱为其父
  - 如果是其父的右孩子并且没有左兄弟，则前驱为其父
  - 如果是其父的右孩子并且有左兄弟，则前驱为其父左子树先序遍历最后访问的结点

找先序后继：
- `rtag=1` 右指针指向的就是后继
- `rtag=0` 
  - 如果有左孩子，则后继为左孩子
  - 如果没有左孩子，则后继为右孩子

先序线索二叉树无法有效查找先序前驱

## 后序线索树找后序前驱/后继

找后序前驱：
- `ltag=1` 左孩子指向的就是前驱
- `ltag=0`
  - 如果有右孩子，则前驱为右孩子
  - 如果没有右孩子，则前驱为左孩子

找后序后继：
- `rtag=1` 右孩子指向的就是后继
- `rtag=0`
  - 如果是整棵树的根，则无后继
  - 如果是其父的右孩子，则后继为其父
  - 如果是其父的左孩子并且没有右兄弟，则后继为其父
  - 如果是其父的左孩子并且有右兄弟，则后继为其父右子树后序遍历的第一个结点

后序线索二叉树无法有效查找后序后继
