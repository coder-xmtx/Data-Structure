# 并查集

利用树的结构来组织集合，用每棵树的根结点来标识集合

- `Find`操作：查询元素属于哪个集合（找根结点）

- `Union`操作：合并两个元素所属的集合（合并相应的根结点）

## 优化

- 查找的优化：路径压缩

- 合并的优化：按秩合并（按高度合并 或者 按大小合并）

合并优化需要另外开一个 `h` 数组或者 `s` 数组，但是其中只需要记录根结点的对应信息，其他结点的值是没用的，有点浪费。

于是，我们可以利用原来记录父结点信息的 `p` 数组，由于根结点的下标值等于元素值，我们可以让元素值改为树的高度信息或者大小信息的负值，
和父结点区别开来。不过，这样子其他函数的代码逻辑就要改一下。
