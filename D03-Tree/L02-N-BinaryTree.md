# 二叉树

## 一、特殊二叉树

- 满二叉树：所有分支结点都有 2 个孩子，所有叶结点都在最后一层，即只有度为 0 和度为 2 的结点
- 完全二叉树：除了最后一层外其余层都是满的；最后一层可以不满，但必须从左到右连续排列

## 二、二叉树的性质

1. 叶结点数 = 度为2的结点数 + 1 （$n_0 = n_2 + 1$）
2. 二叉树的第 $i$ 层最多有 $2^{n-1}$ 个结点
3. 高度为 $h$ 的二叉树最多有 $2^h - 1$ 个结点 （等比数列求和）

## 三、完全二叉树的性质

从上到下，从左到右依次给结点编号 $1,2,\dots,n$

1. 对于 $i$ 号结点，左孩子编号：$2i$，右孩子编号：$2i+1$，父亲结点编号：$\lfloor \frac{i}{2} \rfloor$
2. 最后一个分支结点的编号是 $\lfloor \frac{n}{2} \rfloor$，它和它前面的为分支结点，后面的都是叶结点
3. 最多只可能有一个度为 1 的结点
4. 具有 $n$ 个结点的完全二叉树的高度为 $\lfloor \log_2 n \rfloor + 1$ 或者 $\lceil \log_2 (n+1) \rceil$

注意： 第 4 个性质可通过 $2^{h-1} \le n \le 2^h - 1$ 推出，无非就是放缩哪边的解法
